# Role-claim evidence relevance

General comparison now performs a limited deterministic relevance check before counting evidence for common English role claims. This addresses the last live check, where recent excerpts mentioned the club but did not establish its captain. No additional search or model call is added, and search ranking/query parameters are unchanged.

Recognized claims include `Alex is [not/currently] captain of Acme FC`, `Ada serves as CEO for Acme Corp`, and `Acme Corp's current CEO is Ada`. Supported role anchors include captain/captains/captaincy, CEO/chief executive officer, president, prime minister, chairperson and head coach. Organization/place words and one role anchor must occur together within a sentence in the excerpt. Case, whitespace and Unicode presentation are normalized; whole words prevent names such as `Acme FCX` matching `Acme FC`.

The original claimed person's name is deliberately not required. A report naming a different holder can be useful contradictory evidence. Conversely, an exact name and role occurring together do not prove that the report supports or contradicts the claim: negation, attribution, dates, qualifiers and entity relationships still require semantic comparison. A sentence can contain both anchors while providing no answer. This check only rules out obviously missing anchors.

Historical, conditional, attributed, modal, compound and object-qualified claims recognized by the conservative parser are deferred rather than assigned invented entity boundaries. Unknown wording, multilingual claims, pricing and other topics retain the existing comparison path. Entity aliases, pronouns, cross-sentence references and abbreviations other than the explicitly supported CEO form can cause abstention even for useful evidence. This is not universal entity resolution or a multilingual relevance model.

Nonmatching excerpts remain in citations, with `scopeReason` explaining the missing anchors and `eligible: false`. They cannot supply the two qualifying source groups required for a verdict or correction. Fewer than two qualifying groups causes inconclusive before inference. Existing match-versus-appointment scope checks, date checks, duplicate checks, exact quotes and model assessment rules remain in place. Search-result titles and official-looking URLs cannot substitute for relevant excerpt content.

Offline tests cover affirmative/negative/possessive role patterns, alternative holders, explicit denial, role aliases, partial organization names, unrelated roles, separate-sentence mentions, qualified inputs, pre-inference abstention, retained citations and a third irrelevant source. The saved real-source excerpts can also be replayed without new API requests. Website integration remains separate.

Validation on November 3, 2026: all 419 tests across 31 files using one worker, lint, TypeScript, six fixture regressions and the production build passed. The offline replay of the latest live retrieval excluded both tangential excerpts before inference and retained both citations. No real API requests were made and `.env` was unchanged. This validates rejection behavior, not improved live search coverage or general factual accuracy.
