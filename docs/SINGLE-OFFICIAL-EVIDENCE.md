# Single official source for India's prime minister

The general verifier normally requires two independent source groups for a decisive result. A narrowly reviewed exception allows one recent source from `https://www.pmindia.gov.in/en/news_updates/` or `https://www.pmindia.gov.in/en/pms-profile/` for a claim about India's prime minister. This is a domain and path mapping, not a general rule for government websites or other roles.

The excerpt must directly name a person next to the role. A masthead, historical or conditional wording, outdated evidence, clipped context, and untrusted URLs cannot qualify. The evidence comparison model must still assess the source and provide a valid exact quote. URL ownership alone does not establish that an excerpt is true, complete, or correctly attributed; users should inspect the linked page. Source publication dates depend on retrieval metadata.

For a verdict based on one source, the freshness score and correction remain unavailable: independent corroboration has not been established. Other claims and sources retain the existing corroboration requirements. Results can still be inconclusive if evidence or the model assessment is insufficient.

The change does not add Tavily searches. A source that previously stopped before model comparison may now use one comparison request, within the existing request limits. Re-run an analysis after restarting the backend to see the new behavior; previously saved results are not changed.
